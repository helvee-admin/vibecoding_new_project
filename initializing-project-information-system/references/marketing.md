# 市场推广领域的工作规范

市场推广负责找到目标用户、选渠道与内容、判断推广带来的结果。使用产品已确认的受众假设与能力、适用的品牌资料以及发布侧确认的可交付范围。市场反馈可形成产品线索，产品决定是否改变需求。

## 首批用户与内容

先回答“希望哪一群人，看到什么可信的信息，接下来做什么”。还没有商业结果时，一份推广计划可以只有一个人群假设、一条可接触的途径、一段邀请草稿和一个反馈问题。观察有多少人愿意试、谁完成了核心任务、谁愿意回来以及原因，记清实际人数。讨论潜在渠道时给出选择依据和退出条件。

进入持续推广后，再按团队能维护的频率安排选题。每条内容标明受众场景、要传达的一个利益点、事实或演示依据、渠道形式、希望对方采取的动作及观察方法。同一主题可改写为笔记、短视频、邮件或合作伙伴演示。对外发布、联系用户或花费预算按已有授权执行。

## 选择中国市场或相应渠道时

| 条件 | 可做的小试验 | 怎么判断 |
| --- | --- | --- |
| 目标用户会在小红书搜索经验 | 围绕一个真实使用情境，准备可被搜索的标题、封面和有用的步骤或对比，收集评论里的具体疑问。 | 观察搜索来源、收藏、有效咨询或可核实的试用，选与本次目标相符的一项作主指标。 |
| 目标用户会在抖音看演示 | 写一条可拍的脚本，在开头呈现具体问题，演示结果，留下自然的下一步。对同一主题测试一种开场或剪辑变化。 | 按片段留存找出离开位置，再看有效到达或后续试用。视频时长、受众和分发方式会影响比较。 |
| 正在判断如何在中国市场表达或进入 | 从目标人群的语言、场景、信任依据、地区和渠道习惯重写表达。给趋势信号附来源与日期，用用户访谈、搜索或另一个来源交叉检查。 | 先选择一个可触达的小群体验证理解与行动，再决定扩大或调整。使用当前平台允许的承接方式。 |

目标市场或渠道尚未选定时，只保留渠道选择方法。具体平台玩法、发布时间、算法权重和指标阈值要由当前证据支持。

## 有渠道数据时怎样复盘

- 问清眼前要优化的是触达、试用、有效激活还是付费。列出能观察的链路，例如曝光 → 访问 → 有效试用。按来源、活动、素材和日期标记能关联的步骤。用产品侧的定义解释激活或留存。
- 比较前核对同一观察期、归因窗口、去重单位、自然与付费来源和成本范围。点击率用点击量除以对应展示量。若目标是招募试用者，用约定的推广成本除以可归因的去重试用人数，得到每位有效试用者成本。要评估付费获客才用新增付费客户口径。缺少分母、跨平台无法关联或追踪缺失时，明确写出可判断到哪一步。
- 将内容表现与业务结果并列。播放上涨而试用未动，先排查人群、素材承诺、入口和数据中断。若同来源用户进入产品后在固定步骤流失，带上相应人群与步骤进入产品对话。判断是否加投时，用可比较的有效结果与花费给出维持、缩小或追加小试的理由。渠道归因与活动产生的增量需分别验证。
- 输出一页或计划中的一小节即可。写明目标、真实结果与来源、局限、下一次只改什么、何时据此决定继续或停止。
